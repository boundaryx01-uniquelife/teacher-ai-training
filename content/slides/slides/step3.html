문항을 학생용 퀴즈 페이지로

위 문항 5개로 학생용 퀴즈 웹페이지를 만들어 줘.
- HTML 파일 하나로
- 한 문제씩, 제출하면 정답·해설 표시
- 끝에 점수, 학생 이름은 받지 말 것
- 폰 화면에서도 보기 좋게

  • 무료: 캔버스 미리보기 → HTML 내려받아 더블클릭
  • 유료: 앞에 “@Sites”를 붙이면 주소까지 발급
  • “오답이면 힌트 먼저”처럼 한 가지씩 수정
