# 시각 자료 스타일 가이드

- 스타일: flat illustration, navy #14213D lines/fills, warm paper background #F7F5EF, orange accent #F2A541, no gradients, no shadows, rounded corners, consistent 3px stroke, no text unless listed
- 글꼴: Noto Sans KR (라벨이 있는 경우만)
- 색: 남색 #14213D · 바탕 #F7F5EF · 주황 #F2A541 · 진주황 #A8530A · 보조 글자 #4A5568
- 아이콘: SVG, 120×120 기준, viewBox 0 0 120 120, 선 3px, 둥근 끝, 채움은 남색/주황 2색 이내
- 일러스트: PNG(2배 해상도) + 원본 SVG 함께. 사람은 실루엣/뒷모습만, 실존 인물·캐릭터·브랜드 마스코트 금지
- 화면 캡처: 원본 비율 유지, 슬라이드 상자 크기에 맞춰 여백(바탕색) 패딩, 모서리 16px 라운드, 강조는 주황 3px 테두리 박스로만
- 대체 텍스트: manifest.json의 alt_ko 사용
- 확인: 각 자산을 슬라이드 미리보기(content/slide-previews/)의 점선 상자 위치·크기에 맞는지 비교
