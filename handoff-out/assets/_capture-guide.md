# 화면 캡처·녹화 가이드 (사람이 직접 촬영)

Claude Code는 로그인된 실제 서비스 화면을 찍을 수 없다. 아래 항목은 사람이 촬영해 **원본을 `assets/_raw/`에 파일명 그대로** 넣는다. 크기 맞춤·라운드·강조 박스는 Code의 후처리 스크립트가 한다(HANDOFF S-9).

## 촬영 전 준비 (공통)

- 시연 전용 계정 사용. 실제 학생 이름·성적·연락처·학교 메일이 화면에 보이면 안 된다.
- 가상 자료: `fixtures/`(HANDOFF 부록 S-10 표, fixtures/README.md) — Code가 만들어 둔다. 각 촬영 항목에 어느 파일을 쓰는지 README에 있다.
- 브라우저 확대 100%, 창 너비 1440px, 다크 모드 끔. PNG 2배 해상도.
- 녹화: 1920×1080, 60초 이하, 무음, 대기 구간은 배속 편집. 대표 정지 화면 PNG도 함께.
- 촬영 후 개인정보 흐림 처리 여부를 한 번 더 확인.
