API ① API란 무엇인가

프로그램끼리 정해진 양식으로 부탁하고 답을 받는 창구

1

주문서를 적는다

정해진 양식대로: “급식 메뉴, 부경고, 11월 27일”

2

창구(API)에 낸다

다른 기관의 컴퓨터(서버)로 보낸다 = 요청

3

정해진 그릇에 담겨 온다

결과를 약속된 형식으로 돌려받는다 = 응답

기억할 것 3가지

① 양식대로 부탁한다

② 약속된 형식으로 답이 온다

③ 주방 안(상대 서버)은 몰라도 된다

API = Application Programming Interface(프로그램과 프로그램을 잇는 창구). 이름보다 ‘주문서 창구’로 기억하면 충분하다

API ② 우리는 이미 매일 쓰고 있다

가게·배달 앱 속 지도

직접 지도를 만들지 않고 카카오맵·네이버 지도 API를 불러와 보여 줌

“카카오로 로그인”

공통점: 내 화면(프론트엔드)이 다른 기관의 컴퓨터에 부탁해서 받아 온 자료를 보여 준다

인증키를 주소에 붙여 부탁한다

인증키(API 키) = 출입증

이 창구를 쓸 수 있는 출입증 번호. 누가 얼마나 쓰는지 확인한다. 남에게 보이면 안 되므로 학생 화면이 아니라 서버(백엔드)에 둔다

API ④ 어떻게 부탁하나

인터넷 주소 한 줄이 곧 주문서다

영어 글자는 암호처럼 보이지만 ‘교육청 코드’, ‘학교 코드’ 같은 이름표일 뿐이다

주소 조각뜻
https://open.neis.go.kr/hub/mealServiceDietInfo어느 창구에 — 나이스의 ‘급식 식단’ 창구
?Type=json어떤 그릇에 — JSON 형식으로 달라
&ATPT_OFCDC_SC_CODE=C10교육청 — C10 = 부산광역시교육청
&SD_SCHUL_CODE=7150397학교 — 7150397 = 부경고등학교
&MLSV_YMD=20261127날짜 — 2026년 11월 27일

이 주소를 브라우저 주소창에 넣어도 결과가 나온다. 급식 앱은 이 주소를 대신 불러 주는 프로그램이다

엑셀 표의 ‘열 제목: 칸 내용’을 한 줄씩 적은 것과 같다. 메뉴는 설명용 예시

API ⑥ 직접 받아 보기

부경고 급식을 API로 받아 보자

나이스 교육정보 개방 포털(open.neis.go.kr)은 급식·학사일정·시간표를 API로 공개한다.

open.neis.go.kr/hub/mealServiceDietInfo
?Type=json

&SD_SCHUL_CODE=7150397 ← 부경고
&MLSV_YMD=20261127 ← 날짜

예: “우리 학교 가정통신문 양식·말투로”

연결선(USB처럼)

MCP

AI가 구글 드라이브·캘린더 같은 서비스를 직접 열어 보게 해 주는 연결선. USB 하나로 여러 기기를 꽂듯 한 방식으로 여러 서비스에 연결

드라이브·캘린더·노션 등을 읽고 쓰기

예: “평가 계획서 읽고 캘린더에 일정 등록”

ChatGPT 화면에서는 연결을 ‘앱’, 스킬과 앱을 묶어 설치하는 것을 ‘플러그인’이라고 부른다
